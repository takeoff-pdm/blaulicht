# Code Smells & Architecture Issues
- **Config override & ad-hoc logging** (`crates/core/src/mainloop/mod.rs:94` – `crates/core/src/mainloop/mod.rs:141`): The spectrogram refresh rate and window seconds read from `Config` are immediately overwritten with hard-coded values and debug `println!` calls. This makes the configuration file ineffective, surprises operators, and couples the engine to a TTY.
- **Blocking start-up hack** (`crates/core/src/mainloop/mod.rs:78`): A fixed `thread::sleep(Duration::from_secs(2))` is used to delay plugin initialization. The engine should synchronize on real readiness conditions; the hard sleep adds arbitrary latency and masks races.
- **Panic-prone audio initialization** (`crates/core/src/mainloop/mod.rs:126`, `crates/audio_engine/src/collector.rs:305` – `crates/audio_engine/src/collector.rs:313`): `AudioSourceMicrophone::new` is unwrapped at the call site, and `init_converter` relies on multiple `unwrap()` calls for device metadata. Any missing capability (headless hosts, unplugged devices) will crash the entire engine instead of surfacing a recoverable error.
- **Background worker leaks & hard-coded paths** (`crates/core/src/mainloop/bg_worker.rs:20` – `crates/core/src/mainloop/bg_worker.rs:51`): The spectrogram background worker continuously dumps BMPs into `/home/mik/blaulicht-spec`. This hard-codes a developer path, bypasses configuration, and can fill disks in production. The `unwrap()` calls will crash the worker on any IO error.
- **Plugin ID truncation** (`crates/core/src/state.rs:96` – `crates/core/src/state.rs:111`): Plugin indices are cast to `u8` when populating state maps. The system silently breaks once more than 255 plugins exist, which is an artificial architectural ceiling.
- **Inconsistent spectrogram sizing** (`crates/core/src/state.rs:121` – `crates/core/src/state.rs:124`, `crates/core/src/mainloop/mod.rs:94` – `crates/core/src/mainloop/mod.rs:123`): App state bootstraps a 4-column spectrogram while the main loop rewrites it to a fixed 60 Hz × 10 s buffer. The mismatch causes data to be reshaped at runtime and ignores user-configured values.
- **Global util module suppressing warnings** (`crates/core/src/utils.rs:1` – `crates/core/src/utils.rs:85`): The entire module is silenced with `#![allow(unused)]` and exposes `init_logger` alongside device helpers that rely on more `unwrap()` calls. Mixing logger bootstrapping with IO helpers and suppressing lint noise hides dead code and increases panic surface.
- **UI module monolith & privileged side-effects** (`crates/core/src/app/ui.rs:1402` – `crates/core/src/app/ui.rs:1454`): The 1.7k-line `ui.rs` handles unrelated responsibilities and even shells out to `/usr/bin/shutdown.sh`. Coupling GUI rendering with system-power affordances makes the module impossible to test and ties the build to a specific host environment.
- **Audio analyzer thread handling** (`crates/audio_engine/src/main.rs:93` – `crates/audio_engine/src/main.rs:193`): Worker threads are stored in a map but dropped without joining; panics are lost and threads may continue running after the main loop finishes. The CLI also unwraps decoder and collector creation, turning bad input into process aborts.
- **Plugin WASM host mega-module** (`crates/core/src/plugin/wasm.rs#L1`): At ~1.8k lines this module mixes Wasmtime configuration, host function wiring, per-plugin state, and control bus plumbing. The lack of layering makes it extremely difficult to evolve (e.g., swapping runtimes or testing host functions) and violates separation of concerns.
- **Stale Actix/WebSocket stub** (`crates/core/src/routes/ws.rs:1` – `crates/core/src/routes/ws.rs:120`): The entire route is commented out, leaving a dead module in the tree. Keeping obsolete implementations around increases mental overhead and risks divergence from the actively used API.
- **Uncurated audio engine API** (`crates/audio_engine/src/lib.rs:1` – `crates/audio_engine/src/lib.rs:15`): The crate exports a placeholder `VAR` constant and re-exports every submodule wholesale. The lack of a deliberate public surface leaks internal details and hampers incremental refactors.
